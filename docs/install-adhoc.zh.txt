DiskRings 安装说明（未公证 / ad-hoc 版本）
========================================

本 DMG 为开发者自签（ad-hoc）构建，未经过 Apple 公证。
在较新的 macOS（含 Sequoia）上，首次打开可能被系统拦截——这是正常现象。

一、推荐步骤（系统设置）
------------------------
1. 将「DiskRings」拖到右侧「Applications」（应用程序）文件夹。
2. 在「应用程序」中双击打开 DiskRings。若弹出「无法打开，因为无法验证开发者」：
3. 打开「系统设置」→「隐私与安全性」。
4. 向下滚动，在被拦截的提示附近找到「仍要打开」按钮，点按并输入本机密码确认。
5. 再次打开 DiskRings，应可进入主界面。

二、进阶（可选）：清除下载隔离标记
--------------------------------
仅当上述步骤仍无法打开时再试。此命令只清除本 App 的隔离属性，
不提权、不关闭系统安全功能：

  xattr -dr com.apple.quarantine /Applications/DiskRings.app

- 不需要 sudo
- 只影响上述路径的隔离标记
- 若仍打不开，请回到「系统设置 → 隐私与安全性 → 仍要打开」

三、请勿尝试
------------
- 不要关闭 SIP（系统完整性保护）
- 不要全局关闭 Gatekeeper
- 不要为了安装本软件而执行未知来源的「一键关闭安全」脚本

四、需要完整磁盘访问权限时
--------------------------
扫描部分系统目录时，请到「系统设置 → 隐私与安全性 → 完全磁盘访问权限」
中添加 DiskRings，然后重新扫描。

如有问题，请联系分发方并说明 macOS 版本（本包为未公证 ad-hoc / arm64）。
